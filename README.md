# Breaking_Bytes

## SignSpeak – Sign Language to Text & Speech

SignSpeak is a web-based assistive application that translates sign language gestures into text and speech, helping bridge communication between sign-language users and non-signers.

### Features

- 🤟 Real-time hand gesture recognition
- 📝 Converts gestures into text
- 🔊 Converts recognized text into speech
- 📷 Works using a webcam
- 🌐 Runs directly in a web browser

### Technologies Used

- HTML5
- CSS3
- JavaScript
- TensorFlow.js
- Google Teachable Machine

### Live Project

🌐 [Open SignSpeak](https://connectingthoughts.my.canva.site/)

### How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Allow camera access.
4. Start using the SignSpeak interface.
